# Полевой кодекс: Warhammer 40,000 — Chaos Gate: Daemonhunters

Русскоязычная мобильная вики для **базовой игры + DLC Castellan Garran Crowe** (никаких других DLC).

## Адрес сайта

После включения GitHub Pages в репозитории `fo11e/fo11e.github.io`:

https://fo11e.github.io/chaosgate/

## Настройка публикации

В репозитории открой **Settings → Pages → Build and deployment → Deploy from a branch**, выбери **main** и **/(root)**, нажми Save. Папка `chaosgate/` содержит `index.html`, поэтому работает как отдельный раздел.

## Как дополнять справочник

- `data.js` — массив `window.WIKI` из статей и `window.WIKI_SOURCES` из источников. Каждая статья имеет `id`, `title`, `group`, `summary`, `body`, `refs`, `tags`.
- `index.html` — дизайн, боковое меню, поиск, мобильная адаптация, закладки.
- Новые статьи добавляются в массив `window.WIKI`. Меню и поиск подхватят их автоматически.
- Прямая ссылка на любую статью: `https://fo11e.github.io/chaosgate/#respec`, `#augmetics`, `#enemies`, `#bosses` и т.д.
- Избранное хранится в localStorage браузера и не синхронизируется между устройствами.
